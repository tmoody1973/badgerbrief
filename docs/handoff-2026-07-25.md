## 2. The /news freshness chain (was the recurring "why is news stale" bug)

Four independent links, all now fixed, running unattended daily:

```
scout (11:00 UTC) → verify dates (11:15) → IndexNow ping (11:20) → hub fresh + Bing notified
```

Root causes found this session: scout scanned only 3 of 30 candidates/day (→30); prompt asked "last 90 days"
with no recency filter (→ 7 days + `search_recency_filter: "week"`); relevance gate read only the headline
(→ also reads the URL slug); **and the date verifier had no cron at all** — new articles never got a verified
date, so they sorted below everything and fell off the 60-item hub. That last one was the real culprit.
Crons are in `convex/crons.ts`.

## 4. Key facts a fresh agent will need

- **Data pages are now static/ISR** (`0957c33`). `src/lib/data.ts` wraps every public read in
  `unstable_cache` because `convex/nextjs` `fetchQuery` forces `no-store` + Convex queries are POST (never
  cached by Next). If you add a public read, wrap it in the `cached()` helper there or the page goes dynamic
  again. Admin/per-user reads use client-side Convex hooks and stay dynamic — correct, leave them.
- **IndexNow** (`convex/indexNow.ts`): key file at `public/6bb590d44fd84e0b9b4277fe7bbcb1a9.txt`,
  `INDEXNOW_KEY` set on prod Convex. `submitAll` (one-shot, 457 URLs, already run) and `pingDaily` (cron).
  First submit 403s until Bing validates the key once — that's expected, not a bug.
- **OG card**: `src/app/opengraph-image.tsx`, generated at build, font-free on purpose.
- **Voting-record correctness core**: `convex/lib/rollCall.ts` (state) + `convex/lib/houseVote.ts` (federal).
  The reconciliation gate REPLACES human review and fails closed. Never loosen a check to make a document
  pass — teach the parser the new shape. The `/feedback` form is the deliberate human backstop for the
  gate's blind spot (an internally-consistent doc with swapped positions).
- **WEC = ballot truth.** Candidate names come from the WEC list verbatim, never Ballotpedia/JSON (28 of 256
  names differ). Copy at `.playwright-mcp/All-Contests-and-Candidates.xlsx`.
- **Adding a legislator mapping** requires seeding the name BEFORE ingest, then a destructive re-ingest
  (`votesQueries:deleteSessionVotes` → `votes:ingest`). No reconcile-from-DB path exists.
